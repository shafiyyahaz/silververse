# Silververse 🌌

A lightweight multi-app hub for GitHub Pages.

## Included
- Silververse dashboard
- Silver Xylophone working mini-app
- Coming-soon slots for Lunara, FocusFlow, Pixel Studio, Stellar, Rainroom, ColorLab, and Neko Desktop
- Search, theme toggle, live clock, responsive UI
- No framework, no build step, no external dependencies

## Deploy
1. Create a GitHub repository, e.g. `silververse`.
2. Extract this ZIP and upload the files/folders while keeping the folder structure.
3. Commit to the `main` branch.
4. GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the Pages URL shown by GitHub.

Important: keep `index.html` at the repository root and keep `apps/xylophone/` exactly as shown.
