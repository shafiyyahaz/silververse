SILVERVERSE 2.0
================

Included:
- Surprise Me on every World + dashboard
- Animated star background
- Teleport transition between Worlds
- Achievement system
- Profile & progress saved with localStorage
- Theme Studio: Cosmic Blue, Aurora, Moonlight, Nebula
- Lightweight click sound effects (toggle at bottom-right)
- Responsive mobile layout
- worlds.json data file

Run:
1. Extract the ZIP.
2. Open index.html in a browser, or deploy the folder to GitHub Pages.
3. No build step is required.

Files:
index.html
style.css
script.js
worlds.json
README.txt
