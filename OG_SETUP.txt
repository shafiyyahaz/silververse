Silververse — Open Graph / WhatsApp thumbnail support
=====================================================

Yang ditambahkan:
1. index.html  → meta og:* + twitter:* + canonical
2. og-image.png → 1200×630 px (~118 KB) untuk preview WA/sosmed

Cara deploy ke GitHub Pages:
1. Download zip ini, extract
2. Upload SEMUA isi folder ke repo shafiyyahaz/silververse
   (atau: ganti file index.html + tambah og-image.png saja)
3. Commit & push ke branch main
4. Tunggu 1–2 menit sampai Pages rebuild

Test:
- Buka https://silververse.shafiyyah.my.id/og-image.png  (harus muncul gambar)
- Facebook debugger: https://developers.facebook.com/tools/debug/
  → masukkan https://silververse.shafiyyah.my.id/ → Scrape Again
- Share link HTTPS ke WhatsApp (bukan http://)

Catatan:
- og:image memakai URL absolut HTTPS (wajib untuk WA)
- Domain canonical: silververse.shafiyyah.my.id (CNAME sudah ada di repo)
- Cache WhatsApp bisa lambat; coba ?v=2 jika preview lama belum update
